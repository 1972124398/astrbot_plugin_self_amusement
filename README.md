## 它会做什么

让 AI 在正常聊天之外有一点自己的闲暇。闲下来后，它结合当前人格、心境、最近的话题和兴趣，决定这会儿想做点什么。

| 活动 | 可能的表现 |
| --- | --- |
| 搭讪聊天 | 突然好奇一件小事，找熟悉的人或群聊聊 |
| 碎碎念 | 一个脑洞、一点吐槽、随口的自问自答 |
| 上网闲逛 | 看看感兴趣的内容，可以自己看完先记着 |
| 分享见闻 | 带一条真实来源和自己的感想，顺势开个话头 |
| 继续发呆 | 没有想说的，先自己待一会儿 |

群聊和私聊在**同一个会话列表**里选择，共用一套节奏、兴趣与行为设置。它使用一个全局空闲状态，正常 AI 对话会重新计算空闲时间。

## 想起谁，就去找谁

聊完之后，它会在后台回想“和这里相处起来是什么感觉”。一起接梗、被认真听见、谈到共同爱好时，会更容易惦记这个群或朋友；敷衍、反复冷场或聊得很累时，主动靠近的兴致会降低。

| 相处的感觉 | 后续的自然变化 |
| --- | --- |
| 聊得开心、能互相接话 | 闲下来更容易想到这里，也会带着熟悉的小梗回来 |
| 发现共同兴趣 | 记着下次想聊的事，分享时更偏向双方感兴趣的内容 |
| 主动说了却一直没人理 | 先去别处找乐子，默认两次后等对方回来 |
| 明确说现在忙或不想被找 | 稍后再聊，或先放下主动联系 |
| 曾经疏远，后来又认真接话 | 印象可以慢慢回暖，重新熟络 |

这些感觉按会话保留，群聊和私聊共用同一套偏好设置。新会话仍然有被想起的机会，角色也可以自己逛逛、发呆。状态页会用自然语言展示相处印象。

## 先陪人聊，闲下来再自己玩

正常聊天的请求与回复只留下简短快照，回想感受、选择活动、查找资料、生成闲话和保存状态由后台处理。

- 有人来聊时，放下还没发出的闲话，先接住眼前的人。
- 聊完先等一小会儿，把连续的几句话一起回想，减少反复调用。
- 回想和闲逛独立推进，某次回想很慢时，闲逛计划仍有机会进行。
- `/amuse_preview` 先接单，再于后台琢磨，结果随后回到发起预览的会话。

默认聊天结束后留 10 秒空隙恢复后台活动，相处回想等 20 秒合并近期对话。回想也可以单独选择一个模型。自己的计划被聊天打断、尚未真正发出的内容，会放下重新考虑。

## 快速开始

需要 **AstrBot `>=4.29.4,<5`、Python 3.12+**，以及一个可用的聊天模型。消息平台需要支持主动消息。

1. 在插件管理中通过下方仓库地址安装，或下载 ZIP 后从文件安装。
2. 打开 **插件 → 自娱自乐 → 配置**。
3. 在“可以主动搭话的会话”中一起选择需要的群聊和私聊。
4. 保存后开始正常聊天，闲下来后它会自己琢磨活动。

```text
https://github.com/1972124398/astrbot_plugin_self_amusement
```

也可由管理员在目标会话发送 `/amuse_here`，把当前会话加入统一列表。默认目标为空，选择会话后才会开始主动活动。

## 默认的日常节奏

| 项目 | 默认值 |
| --- | --- |
| 聊完多久开始琢磨 | 随机等待 15～45 分钟 |
| 两次主动发话 | 全局至少间隔 20 分钟 |
| 同一个会话 | 主动发话至少间隔 60 分钟 |
| 没人接话 | 连续两次后先放下，等对方回来 |
| 一天主动发起 | 所有会话合计最多 12 次 |
| 安静时段 | AstrBot 主机时间 00:00～08:00 |
| 消息长度 | 正文最多 220 字，分享另附来源 |

这些参数都能在配置窗口修改。它有时会选择只浏览或发呆，因此到时间也可能没有消息。计划完成前若有人开始正常对话，会先放下这次主动发言。

“记住和谁相处开心”默认开启，可选择温和、自然偏心或更随心的倾向。无人接话也可以改成“歇一阵后偶尔想起再聊”，那时使用默认 180 分钟的暂歇时间。

## 偶尔自己动手，做好再来给你看

同时安装 Codex Bridge 2.7.0+ 后，“无聊时可以做的事”新增 `codex`：围绕人设、共同兴趣和最近的话题，偶尔做个小网页、小游戏、小工具、资料整理，或把明确委托过的想法做成独立原型。先悄悄开工，等真实结果回来，再按性格决定要不要分享、稍微得意一下。没有做成就如实表达，也可以自己收着，不固定索要夸奖。

新配置默认包含这个选项。已有配置若保存过活动列表，需要在列表中勾选“偶尔借 Codex 动手做点小东西”。默认每轮空闲思考只有 **5%** 概率获得该选项，模型仍可能选别的活动，实际开工更少。Bridge 默认再限制为 **6 小时冷却、每天最多 2 次**，有排队或运行中的任务时先避让。

作品在独立目录与新 Codex 聊天中完成。成果保存在 Bridge 中，重启后仍可继续分享；分享沿用安静时段、每日发话上限、发话间隔和没人回应时先退让的规则，只回原会话。预览命令仅展示想法，不会创建任务。取消 `codex` 或关闭联动后暂停这一能力；概率设为 0 只停新开工，已有成果仍可分享。

## 网上看看与分享

优先复用目标会话在 AstrBot 中配置并启用的联网搜索。支持当前 SDK 内置的 Tavily、Bocha、Brave、Firecrawl、Baidu、Exa、AnySearch、DeepSeek 和 SerpApi 搜索。

搜索不可用时，会读取配置中的 RSS / Atom 订阅。默认带有 Solidot 与 IT 之家，可替换成角色自己的兴趣来源。RSS 按订阅浏览，内容范围由所填源决定。

分享从实际取得的材料里选一条，附上真实来源链接。资料不可用时，这轮可以先待着。浏览本身也可以留作自己的兴趣，之后再产生话头。

## 命令

以下命令需要 AstrBot 管理员权限。

| 命令 | 用途 |
| --- | --- |
| `/amuse_here` | 把当前群聊或私聊加入统一目标列表 |
| `/amuse_remove` | 把当前会话从列表中移除 |
| `/amuse_status` | 查看正在做什么、下次活动时间与最近闲念 |
| `/amuse_social` | 查看和当前会话相处的感觉、共同兴趣与没聊完的话头 |
| `/amuse_forget` | 放下当前会话先前的印象，之后重新认识 |
| `/amuse_preview` | 后台预览一次想法和发言，结果随后回到当前会话 |

预览先返回接单提示，后台完成后再展示结果。预览也会产生模型或联网调用，自动活动的次数保持原值。

## 和现有插件一起用

- **短期共享情绪**可以提供此刻心境，并用其人格化表达修饰主动消息。主动活动本身沿用该插件的 `proactive:` 事件标识。
- **消息合并与普通回复**继续处理正常聊天。主动消息在后台生成，下一轮正常回复会收到当前会话最近主动说过的话，方便接续。
- **已有主动聊天插件**可以同时保留，但两者有各自计划。自娱自乐观察经过标准 LLM 钩子的对话和其他主动回复，从而重新计算自己的空闲时间。若同时对同一会话启用，可结合实际节奏调整。
- **微信 Native**通过适配器已有发送接口投递，支持范围仍取决于平台本身的群聊或私聊能力。

其他会话的聊天内容保留在原会话。当前活动参考目标会话的背景，共享的是闲暇节奏、兴趣念头与可选的情绪。
